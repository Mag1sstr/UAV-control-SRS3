# AeroSense — учебный симулятор ИСУ БПЛА

Одностраничное приложение React + TypeScript + Vite для прохождения семи этапов проектирования интеллектуальной системы управления БПЛА.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```bash
npm install
npm run dev
```

Vite покажет адрес приложения, обычно `http://localhost:5173`. Production-сборка: `npm run build`; локальный просмотр сборки: `npm run preview`.

## Что можно выполнить в приложении

1. **Сбор данных.** Загрузить CSV/JSON, выделить числовые поля, обработать пропуски, применить медианное сглаживание, фильтр Калмана к GPS-колонкам, min–max нормализацию и разделить выборку на обучение/проверку/тест. Для изображения выполняется нормализация контраста и медианный фильтр 3 × 3 на Canvas (операции, аналогичные OpenCV).
2. **Траектория.** Строить круговой маршрут, восьмёрку или маршрут обхода препятствий алгоритмом A*. Высота задаёт безопасный буфер препятствий, скорость пересчитывает время облёта.
3. **Управление.** Настраивать Kp/Ki/Kd и ошибку курса, запускать дискретную PID-симуляцию реакции условного аппарата.
4. **ИИ и обнаружение.** Рассчитывать регрессию МНК на загруженном датасете, линейный SVM, CNN–LSTM с демонстрационными коэффициентами, дерево, Random Forest, XGBoost, Мамдани и EKF. Импортировать JSON-выход YOLOv8, преобразовать центр рамки в координату с учётом высоты и курса камеры.
5. **Карта и решения.** Просматривать маршрут и препятствия на 2D-схеме, наносить импортированное обнаружение, проверять ветвление по кадру, аномалии и достоверности GPS.
6. **Координаты.** Переводить WGS‑84 в локальную ENU-систему через ECEF на эллипсоиде WGS‑84.
7. **NDVI.** Рассчитывать индекс по NIR и Red, классифицировать диапазон фитостресса и менять порог решения о повторной съёмке.

Параметры этапов сохраняются в `localStorage`. Отчёт можно скачать на седьмом этапе.

## Границы учебного режима

Приложение выполняет локальные вычисления и симулирует контур PID; оно не управляет настоящим дроном. Камера, IMU, автопилот и живой поток телеметрии не подключены. Предобученные веса YOLOv8 и обученные веса нейросетей не включены: модуль принимает JSON-результат детектора для геопривязки, а CNN–LSTM показан вычислительным примером с демонстрационными коэффициентами. Регрессия обучается на загруженном наборе, если найдены признаки ветра и скорости; SVM, Random Forest и XGBoost демонстрируются на синтетических числовых примерах.
